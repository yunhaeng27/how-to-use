# 매뉴얼

GenOS의 서비스 적응을 위한 각종 기능에 대한 세부 설명, 가이드 작성 시 참고용 정보를 모아둔 저장소.

각 기능의 단순 사용법은 공식문서들을 보는게 더 나음. 여기서는 GenOS 내에서의 개발, 연동 등을 기술하여 개발 시 시행착오를 줄이는 것이 목표.

> [!NOTE]
> 수정, 변경 자유롭게 가능함.

> [!IMPORTANT]
> GenOS나 각 라이브러리 버전에 따라 내용 차이가 있을 수 있음.

## 목차

- [01_Langfuse](01_Langfuse/README.md) — Langfuse 사용법, GenOS 등 사내 서비스 연동 예제/케이스
- [99_GenOS](99_GenOS/README.md) — 여러 가이드에 걸쳐 재사용되는 GenOS 공용 내용

## 디렉토리 구조

각 디렉토리는 아래와 같은 공통 구조를 사용하여, 어떤 가이드에 접근해도 구조를 파악하기 쉽게 함.

```
/NN_가이드명
├── README.md   # 해당 가이드 랜딩 페이지. 개요, 목차(인덱스) 등
├── NN_주제명.md # 세부 문서(00부터 순서대로)
├── assets/     # 가이드 작성에 필요한 사진들 모음
└── codes/      # 코드 예제
```
