# GenOS 가이드

> [!NOTE]
> 해당 GenOS 가이드는 실제 GenOS에서 제공하고 있는 메뉴얼과는 별도.

해당 레포 가이드 중 GenOS 관련 내용이 들어가야하는 경우 + 해당 가이드에 들어가기에는 내용이 너무 많은 경우 해당 GenOS에 정리하고 각 가이드를 연결한다.

전체적인 사용자 메뉴얼이나 공식 정보는 GenOS 깃북이나 메뉴얼을 확인할 것.
